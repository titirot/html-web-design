# 🌸 Titi Fitness — Country Club Website

A responsive and vibrant promotional web application designed for a country club and fitness center, featuring a modern color palette, an interactive photo gallery, and dedicated pages for various training facilities and classes.

🔗 **Repository:** [https://github.com/titirot/html-web-design.git](https://github.com/titirot/html-web-design.git)

---

## 📖 About The Project

The website showcases the country club's offerings and allows visitors to easily navigate through different sections via a clean navigation bar. The interactive gallery links directly to specific training zones and fitness programs.

---

## ✨ Key Features & Pages

- **🏠 Home Page:** Welcoming landing page introducing the club.
- **🖼️ Gallery:** Visual showcase of the facility's training areas.
- **💪 Strength Training:** Dedicated page for strength and weightlifting zones.
- **🏃‍♀️ Aerobics:** Dedicated page for aerobic activities.
- **🧘‍♀️ Pilates:** Dedicated page for the Pilates studio.
- **💃 Studio Classes:** Information on various group fitness sessions.
- **ℹ️ About Us:** Background information about the country club.
- **📞 Contact:** Inquiry and contact page.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup and structure
- **CSS3:** Custom styling featuring a vibrant pink and turquoise color palette, Flexbox/Grid layouts, card components, and interactive hover effects.
